A one-page newspaper front page, "The World Today", summing up the world news of Sunday 22 November 2026. The G20 summit opening in Johannesburg, the first held in Africa, leads, with six more stories in politics, markets, tech and defence and a ticker at the foot. Everything is drawn with flat Pillow shapes by `render.py`, and `main.py` copies the committed `entry.png` to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

To redraw the image: `python3 render.py` (needs Pillow and DejaVu fonts).
